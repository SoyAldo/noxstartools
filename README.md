# NoxstarTools 🌌

NoxstarTools es una suite integral y avanzada de herramientas web diseñada específicamente para administradores, desarrolladores y dueños de servidores de Minecraft. Construida con tecnologías modernas para ofrecer un rendimiento óptimo y una experiencia de usuario premium, dinámica y adaptable.

## 🚀 Características y Herramientas

La plataforma incluye una variedad de utilidades esenciales para la gestión diaria de un servidor de Minecraft:

*   **📡 Estado de Servidores (Server Status):** Consulta en tiempo real el estado de cualquier servidor, con soporte completo tanto para **Java Edition** como para **Bedrock Edition**. Visualiza jugadores en línea, versión requerida, MOTD en bruto y limpio, e información detallada de red y depuración.
*   **🎨 Generador de Colores Hexadecimales (Hex Generator):** Crea fácilmente gradientes y formatos de color hexadecimales compatibles con los plugins más populares de chat y mensajes de Minecraft.
*   **⚡ Analizador de Spark (Spark Analyzer):** Herramienta integrada para interpretar y analizar reportes de rendimiento de Spark Profiler de una manera más rápida y eficiente.
*   **✅ Validador de Código (Validator):** Utilidad para validar la sintaxis de archivos de configuración como YAML o JSON para prevenir errores antes de reiniciar el servidor.
*   **🔌 Gestor de Plugins (Plugins):** Un buscador e indexador de plugins útiles para armar tu servidor de forma óptima.

## 💻 Stack Tecnológico

NoxstarTools está desarrollado utilizando las mejores prácticas de la web moderna:
*   **Core:** React.js con TypeScript
*   **Build Tool:** Vite (Superrápido y optimizado)
*   **Estilos:** TailwindCSS para un diseño responsivo, estético y con dark mode.
*   **Fetch & Estado:** TanStack Query (React Query) y Axios.
*   **Iconografía:** Lucide React.

## 🛠️ Instalación y Uso Local

Para ejecutar NoxstarTools de forma local en modo de desarrollo:

1.  Asegúrate de tener Node.js y `pnpm` (o `npm`/`yarn`) instalados.
2.  Instala las dependencias del proyecto:
    ```bash
    pnpm install
    ```
3.  Inicia el servidor de desarrollo local:
    ```bash
    pnpm run dev
    ```
4.  Abre la URL proporcionada (usualmente `http://localhost:5173`) en tu navegador.

Para construir para producción:
```bash
pnpm run build
```
